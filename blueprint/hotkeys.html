핫키 배치

모든 캐릭터가 같은 자리에 같은 역할을 둔다. 배치는 두 유형이고 Razor 프로필 하나가 유형 하나다.

유형 누구 Razor 프로필
summoner 소환수·펫을 부리는 캐릭터 summoner
basic 그 밖의 캐릭터 (기본형) default

유형이 가르는 칸은 아랫줄 (1.5절)뿐이다. 템플릿이 채우는 칸은 1 2 3, F1, F4, Alt 줄이다 (3절). 바인딩의 정본은 Razor 프로필 xml과 ClassicUO의 macros.xml, profile.json이다 (2.3절). 이 문서는 그것을 사람이 읽는 배치도다.

1. 키 배치

키보드 줄마다 표 하나다. —는 빈칸, (예정)은 자리만 정하고 아직 걸지 않은 칸이다.

Mac에서는 Wine이 Cmd → Ctrl, Option → Alt로 넘긴다 (prefix/user.reg의 LeftCommandIsCtrl, LeftOptionIsAlt). 이 문서의 Ctrl은 엄지로 누르는 Cmd, Alt는 Option이다.

1.5 아랫줄

Z → V가 공격이다. 어느 유형이든 Z로 시작해서 V로 끝낸다. 유형마다 키의 뜻은 달라도 두 키를 이어 누른 결과는 "가장 가까운 몹을 친다"로 같다. 이 줄에서 유형마다 다른 칸은 Z X C V의 무수정과 Shift뿐이다.

Z X C V B N
무수정 · summoner All Kill (커서) All Follow Me All Guard Me 가장 가까운 몹 타겟 moongate home
무수정 · basic 가장 가까운 몹 타겟 이전 플레이어 다음 플레이어 Attack Last Target moongate home
Shift · summoner — 이전 플레이어 다음 플레이어 Attack Last Target — —
Shift · basic 햄스트링 켜기/끄기 (예정) 디스암 켜기/끄기 (예정) — — — —
Ctrl Wall of Stone Mass Dispel Invisibility Reveal — —
Alt — — — — — —
  • summoner는 Z가 All Kill 커서를 띄우고 V가 그 커서를 가장 가까운 몹으로 채운다. 커서가 없을 때 V는 라타만 잡는다.
  • basic은 Z로 라타를 잡고 V로 친다. PvP에서는 X / C로 플레이어를 잡고 V를 누른다.
  • 플레이어 순환은 summoner가 Shift+X/C, basic이 무수정 X/C다. 키 하나에는 바인딩이 하나만 걸리는데 summoner는 무수정 X / C를 펫 명령이 쓴다.
  • summoner는 Follow를 X, Guard를 C에 둔다. C는 가장 자주 누르는 V 바로 옆이라 잘못 누르기 쉽다. Guard는 잘못 눌러도 펫이 싸움을 이어 가지만 Follow를 누르면 펫이 싸움을 멈춘다.
  • 햄스트링·디스암은 평소 켜 둔다. basic의 Shift+Z / Shift+X는 상황에 따라 끄고 켜는 자리다 (예정, 7절). 켜고 끄면 프로필 오버헤드 [ hams mode, on/off ] [ disarm mode, on/off ]가 뜬다 (overheads.html 7절).
  • 무기 스왑 (hotkey/weapon-*)은 스크립트라 누르면 돌던 전투 루프가 멈춘다. 이 줄에 넣지 않는다.

2. 규칙

2.1 층

층 뜻 줄별
무수정 손에 익어야 하는 것 이동, 타겟, 펫, 핵심 콤보, 도주, 긴급
Shift 밖으로 던지는 것 윗줄 공격 주문 6, 아랫줄 교전 (summoner는 플레이어 순환, basic은 햄스트링·디스암)
Ctrl 나와 내 편에 좋은 것 숫자줄 포션 6, 윗줄 버프 4 + 펫 큐어 + 동료 부활, 아랫줄 필드·유틸 4, ` 펫 힐
Alt 소환만 1 VS → 2~6. 예외는 0 dress 하나다 (1.2절). 전투 밖에서 천천히 누른다

2.2 Mac에서 막히는 키

Ctrl은 Cmd로, Alt는 Option으로 누르므로 (1절) macOS가 먼저 가져가는 키가 있다.

키 무엇이 막나 대처
Ctrl+Space macOS가 먹는다 쓰지 않는다
Ctrl+` macOS 기본 단축키 "다음 윈도우로 초점 이동"이 먹는다 시스템 설정 → 키보드 → 키보드 단축키 → 키보드에서 그 항목을 끄고 쓴다
Alt+` Option+`이 악센트 dead key라 게임에 안 들어온다 쓰지 않는다. Alt 줄은 1부터

2.3 어디에 거는가

어디 무엇 메모
Razor 프로필 <hotkeys> Razor 핫키로 되는 것 전부: 주문, 네크로 능력, 스킬, 타겟, 펫, 포션, Pouch, 힐, 스크립트 프로필 하나가 유형 하나라 한 파일만 고치면 그 유형의 캐릭터 전부에 적용된다
ClassicUO macros.xml Razor에 없는 것만: 말하기 (bank guards, [recallcharge Houseboat, [vendor, all release), 클라이언트 UI (F5 이름 표시, F6 투명, Set Bag), 화면에서 클릭해 쓰는 하이드·명상 (키 없음) 캐릭터마다 따로다. 되도록 적게, 캐릭터끼리 같게 둔다
ClassicUO profile.json 이동 키 W A S D (walk_up_key 등) 캐릭터마다 따로다
인게임 카운터·핫바 걸지 않는다 파일에 없는 바인딩은 저장소가 못 지킨다

프로필이 HotKeyStop=True라 Razor에 걸린 키는 ClassicUO로 넘어가지 않는다. 같은 키를 양쪽에 걸면 ClassicUO 쪽 매크로는 조용히 죽는다.

7. 확인 안 된 것

  • 인게임 카운터·핫바에 남아 있던 포션, T, Y 바인딩을 풀었는지.
  • 메이지의 1 2 3 = Curse / Weaken / Clumsy와 F1 = hally-mage가 실제 템플릿에 맞는지. 지금은 임시로 배정했다.
  • 사이드 위/아래가 코드 -5 / -4와 맞는지. 눌러 보고 반대면 두 줄을 맞바꾼다.
  • macOS의 "다음 윈도우로 초점 이동"을 끈 뒤 Ctrl+`이 게임에 들어오는지.
  • 아랫줄 새 배치 (summoner.xml, default.xml)가 게임에서 그대로 도는지.
  • 햄스트링·디스암 토글을 어떻게 거는지 (Razor 핫키, 채팅 명령, 버튼). 위키 Hamstring 문서에서 확인하고 basic의 Shift+Z / Shift+X에 건다.
  • Razor로 옮긴 주문 핫키 (L:3002011 ~ L:3002074)가 Outlands에서 그대로 도는지. CE 규칙으로 계산한 번호라 이 포크에서 게임으로 확인하지 않았다. 주문 매크로는 여섯 캐릭터의 macros.xml에서 이미 지웠다. 안 도는 키는 Razor Hotkeys 탭에서 다시 걸고 종료해 프로필에 저장한다.
