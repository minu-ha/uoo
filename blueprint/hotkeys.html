핫키 배치

모든 캐릭터가 같은 자리에 같은 역할을 둔다. 배치는 두 유형이고, Razor 프로필 하나가 유형 하나다.

유형 누구 Razor 프로필
summoner 소환수·펫을 부리는 캐릭터 summoner
basic 그 밖의 캐릭터 (기본형) default

유형이 가르는 칸은 아랫줄 (2.5절)뿐이다. 템플릿이 채우는 칸은 1 2 3, F1, F4, Alt 줄이다 (3절). 바인딩의 정본은 프로필 xml 과 macros.xml 이고, 이 문서는 그것을 사람이 읽는 배치도다.

1. 규칙

1.1 층

층 뜻 줄별
무수정 손에 익어야 하는 것 이동 · 타겟/펫 · 핵심 콤보 · 도주 · 긴급
Shift 밖으로 던지는 것 윗줄 공격 주문 5, 아랫줄 교전 (summoner 는 플레이어 순환, basic 은 햄스트링·디스암)
Ctrl 나와 내 편에 좋은 것 숫자 포션 6, 윗줄 버프 4 · 펫 큐어, 아랫줄 필드·유틸 4, ` 펫 힐
Alt 소환. 그것뿐 1 VS → 2~6. 전투 밖에서 천천히 누른다

1.2 Mac 에서 막히는 키

Wine 이 Cmd → Ctrl, Option → Alt 로 넘긴다 (prefix/user.reg 의 LeftCommandIsCtrl, LeftOptionIsAlt). 이 문서의 Ctrl 은 엄지로 누르는 Cmd, Alt 는 Option 이다.

키 무엇이 막나 대처
Ctrl+Space macOS 가 먹는다 쓰지 않는다
Ctrl+`` ``` macOS 기본 단축키 "다음 윈도우로 초점 이동" 이 먹는다 시스템 설정 → 키보드 → 키보드 단축키 → 키보드 에서 그 항목을 끄고 쓴다
Alt+`` ``` Option+` 이 악센트 dead key 라 게임에 안 들어온다 쓰지 않는다. Alt 줄은 1 부터

1.3 어디에 거는가

어디 무엇 메모
Razor 프로필 <hotkeys> Razor 핫키로 되는 것 전부: 주문, 네크로 능력, 스킬, 타겟, 펫, 포션, Pouch, 힐, 스크립트 프로필 하나가 유형 하나라 한 파일만 고치면 그 유형의 캐릭터 전부에 적용된다
ClassicUO macros.xml Razor 에 없는 것만: 말하기 (bank guards, [recallcharge Houseboat, [vendor, all release), 클라이언트 UI (F5 이름 표시, F6 투명, Set Bag), 화면에서 클릭해 쓰는 하이드·명상 (키 없음) 캐릭터마다 따로다. 되도록 적게, 캐릭터끼리 같게 둔다
인게임 카운터·핫바 걸지 않는다 파일에 없는 바인딩은 저장소가 못 지킨다

프로필이 HotKeyStop=True 라 Razor 에 걸린 키는 CUO 로 넘어가지 않는다. 같은 키를 양쪽에 걸면 CUO 쪽 매크로는 조용히 죽는다.

2.5 아랫줄

Z → V 가 공격이다. 어느 유형이든 Z 로 시작해서 V 로 끝낸다. 유형마다 키의 뜻은 달라도 두 키를 이어 누른 결과는 "가장 가까운 몹을 친다" 로 같다.

summoner (프로필 summoner):

Z X C V B N
무수정 All Kill (커서) All Follow Me All Guard Me 근접 몬스터 타겟 moongate home
Shift — 이전 플레이어 다음 플레이어 Attack Last Target — —
Ctrl Wall of Stone Mass Dispel Invisibility Reveal — —
Alt — — — — — —
  • Z 가 All Kill 커서를 띄우고 V 가 그 커서를 가장 가까운 몹으로 채운다. 커서가 없을 때 V 는 라타만 잡는다.
  • Follow 를 X, Guard 를 C 에 둔다. C 는 가장 자주 누르는 V 바로 옆이라 잘못 누르기 쉬운데, Guard 는 잘못 눌러도 펫이 싸움을 이어 간다. Follow 는 펫이 싸움을 멈춘다.

basic (프로필 default):

Z X C V B N
무수정 근접 몬스터 타겟 이전 플레이어 다음 플레이어 Attack Last Target moongate home
Shift 햄스트링 켜기/끄기 디스암 켜기/끄기 — — — —
Ctrl Wall of Stone Mass Dispel Invisibility Reveal — —
Alt — — — — — —
  • Z 로 라타를 잡고 V 로 친다. PvP 는 X / C 로 플레이어를 잡고 V.
  • 플레이어 순환이 summoner 는 Shift+X/C, basic 은 무수정 X/C 로 다르다. 키 하나에는 바인딩 하나만 걸리므로 두 곳에 같이 걸 수 없다.
  • 햄스트링·디스암은 평소 켜 둔다. Shift+Z / Shift+X 는 상황에 따라 끄고 켜는 용도. 켜고 끄면 프로필 오버헤드 [ hams mode, on/off ] [ disarm mode, on/off ] 가 뜬다.
  • 무기 스왑 (hotkey/weapon-*)은 스크립트라 누르면 돌던 전투 루프가 멈춘다. 이 줄에 넣지 않는다.

7. 확인 안 된 것

  • 인게임 카운터·핫바에 남아 있던 포션 · T · Y 바인딩 해제.
  • 메이지의 1 2 3 = Curse / Weaken / Clumsy 와 F1 = hally-mage 는 임시 배정. 실제 템플릿에 맞춰 바꾼다.
  • 사이드 위/아래는 코드 -5 / -4 로 배정했다. 눌러 보고 반대면 두 줄을 맞바꾼다.
  • macOS 의 "다음 윈도우로 초점 이동" 을 끈 뒤 Ctrl+`` ``` 가 게임에 들어오는지.
  • Ctrl+T Cure (nomeehej, xuezhonglian 의 macros.xml)와 아랫줄 새 배치 (summoner.xml, default.xml)가 게임에서 그대로 도는지.
  • 햄스트링·디스암 토글을 어떻게 거는지 (Razor 핫키, 채팅 명령, 버튼). 위키 Hamstring 문서에서 확인하고 basic 의 Shift+Z / Shift+X 에 건다.
  • Razor 로 옮긴 주문 핫키 (L:3002011 ~ L:3002074)가 Outlands 에서 그대로 도는지. CE 규칙으로 계산한 번호라 이 포크에서 게임으로 확인하지 않았다. 여섯 캐릭터의 macros.xml 에서 주문 매크로는 이미 지웠으니, 안 도는 키는 Razor Hotkeys 탭에서 다시 걸고 종료해 프로필에 저장한다.
