# script/

Grouped by what a script does. Folders say *what*, file names say *which*.

```
combat/    hunting loops, one per template
hotkey/    one-shot macros bound to a key: weapon swaps, dress, cancel target, bard buffs, moongate, dump-label
train/     skill trainers
gather/    mining, lumberjacking
loot/      what you do with what you picked up: share-loot, claim-loot, recycle, bank-pouch, stock-vendor
restock/   getting ready to go out: loadout, refill-runebook
shelf/     Storage Shelf loadouts generated by outlandsbutler.com, one per template
```

Combat loops are named after the template (`bard-mace`, `hally-mage`), variants get a suffix (`bard-necro-enhanced`, `bard-necro-pvp`), everything else is `verb-noun` (`refill-runebook`,
`stock-vendor`). The full rules are in [blueprint/conventions.html](../blueprint/conventions.html).

## Combat loops

| Script                | Template                                                                                     |
|-----------------------|----------------------------------------------------------------------------------------------|
| `bard-necro-enhanced` | Discord / Peace / Provo + Necromancy summons + Spirit Speak, with the Grimoire proc rotation |
| `bard-necro-pvp`      | Bard Necro against a player killer: survive, Telekinesis, explosion dump. F4 while hunting   |
| `bard-mace`           | Bard dexxer with maces                                                                       |
| `bard-throwing`       | Bard dexxer with throwing weapons: Throwing Codex stances, moving-throw readout              |
| `hally-mage`          | Weapon-swap mage: halberd / katana / viking sword                                            |
| `dexxer-basic`        | Minimal dexxer sustain: bandages, potions, healing                                           |
| `backstab-mugging`    | Stealth backstab thief                                                                       |

A new combat loop gets a row here. Every loop has the same shape, set out in
[blueprint/conventions.html](../blueprint/conventions.html#02.B) 02.B: config and state first, then one `while not dead` loop.

## Personal values never go into a script

These files are shared. A container serial typed into one is *someone else's* container for
everyone who pulls it. Keep such values in your Razor profile instead:

```
if not varexist global__my_loot_container
    overhead "[ loot chest, pick ]" 55
    setvar global__my_loot_container
endif
```

`setvar` asks for a target once and stores the serial in your profile; the script carries only the
name (this is `loot/claim-loot`). `gather/mining`, `gather/lumberjack` and `loot/bank-pouch` still
hardcode serials and are being converted. `shelf/` scripts are generated with their owner's shelf serial.

## Checking a script

```sh
util/check.sh                       # every script
util/check.sh script/combat/bard-necro-enhanced.razor
```

Razor has no linter and a missing `endif` is the usual way a script silently misbehaves. `check.sh`
reports unbalanced or mismatched `if / while / for` blocks, and prefixed variables used before anything
assigns them, with line numbers. Bash and awk only.
