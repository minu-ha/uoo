# script/

Grouped by what a script does. Folders say *what*, file names say *which*.

```
combat/    hunting loops per template, shared PvP self sustain
hotkey/    one-shot macros bound to a key: weapon swaps, dress, cancel target, bard buffs, moongate
debug/     diagnostics and test scripts: dump-label, target find/state probes, Telekinesis variable test
train/     skill trainers
gather/    mining, lumberjacking
loot/      what you do with what you picked up: share-loot, claim-loot, recycle, bank-pouch, stock-vendor
restock/   getting ready to go out: loadout, refill-runebook
shelf/     Storage Shelf loadouts generated by outlandsbutler.com, one per template
```

Combat loops are named after the template (`bard-mace`, `hally-mage`), variants get a suffix (`bard-necro-enhanced`), shared PvP uses `pvp`, and everything else is `verb-noun` (`refill-runebook`,
`stock-vendor`). The full rules are in [blueprint/conventions.html](../blueprint/conventions.html).

## Combat loops

| Script                | Template                                                                                     |
|-----------------------|----------------------------------------------------------------------------------------------|
| `bard-necro-enhanced` | Discord / Peace / Provo + Necromancy summons + Spirit Speak, with the Grimoire proc rotation |
| `pvp`                | Shared field PvP self sustain with Magery, bandage, potion and optional rearm settings; all offense stays manual |
| `bard-mace`           | Bard dexxer with maces                                                                       |
| `bard-throwing`       | Bard dexxer with throwing weapons: Throwing Codex stances, moving-throw readout              |
| `hally-mage`          | Weapon-swap mage: halberd / katana / viking sword                                            |
| `dexxer-basic`        | Minimal dexxer sustain: bandages, potions, healing                                           |
| `backstab-mugging`    | Stealth backstab thief                                                                       |

A new combat loop gets a row here. Every loop has the same shape, set out in
[blueprint/conventions.html](../blueprint/conventions.html#02.B) 02.B: config and state first, then one `while not dead` loop.

## Personal values never go into a script

These files are shared. A container serial typed into one is *someone else's* container for
everyone who pulls it. Keep such values in your Razor profile instead:

```
if not varexist global__my_loot_container
    overhead "[ loot chest, pick ]" 55
    setvar global__my_loot_container
endif
```

`setvar` asks for a target once and stores the serial in your profile; the script carries only the
name (this is `loot/claim-loot`). `gather/mining`, `gather/lumberjack` and `loot/bank-pouch` still
hardcode serials and are being converted. `shelf/` scripts are generated with their owner's shelf serial.

## Checking a script

```sh
util/check.sh                       # every script
util/check.sh script/combat/bard-necro-enhanced.razor
```

Razor has no linter and a missing `endif` is the usual way a script silently misbehaves. `check.sh`
reports unbalanced or mismatched `if / while / for` blocks, and prefixed variables used before anything
assigns them, with line numbers. Bash and awk only.

## Shared PvP sustain

Use [combat/pvp.razor](combat/pvp.razor) for every template. Set `config__pvp_preset` in that file (1: mage, 2: bandage mage),
then put capability overrides after the preset block. Bind PvP hotkeys to `Play Script: combat\pvp`.
`config__pvp_magery = 0` disables automatic spells, `config__pvp_bandage = 1` enables self bandages, and
`config__pvp_weapon_graphic = 0` leaves equipment manual. A nonzero graphic ID rearms only when both hands are empty.

Attack spells, TK, explosion potions, pet attacks, Hamstring and weapon swaps stay manual. Existing casting or target cursors pause
all automatic actions, including healing. Stop the script before starting another spell during an automatic self cast.
Settings, cursor handling and pending in-game checks are in [the PvP blueprint](../blueprint/pvp.html#05.E).

## Debug scripts

Diagnostics live in `debug/`. Stop the combat loop before running a probe or the Telekinesis test.

| Script | Purpose |
|--------|---------|
| [dump-label](debug/dump-label.razor) | Print the exact label returned for a selected item |
| [debug-target-find](debug/debug-target-find.razor) | Compare serial lookup, range filters and optional body scans |
| [debug-target-state](debug/debug-target-state.razor) | Inspect target state, variable comparison and readiness gates |
| [test-telekinesis-var](debug/test-telekinesis-var.razor) | Cast one Telekinesis using a manually stored target serial |

After moving a script, rebind any old hotkey to its `debug\...` path. The probe results are recorded in
[the Razor blueprint](../blueprint/razor.html#03.A).
