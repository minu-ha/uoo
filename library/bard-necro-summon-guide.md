# Bard-Necro Summon Combo Guide

## 대상 플레이 스타일

- 캐릭터 전제
  - `Discordance 120 / Peacemaking 120 / Provocation 120`
  - `Magery 100 / Necromancy 120 / Spirit Speak 120 / Herding 20`
- 운영 전제
  - `Perfect Pitch`, `Self Taught` 고정
  - `Peace <-> Provo` 스위치 사용 가능
  - 테이머 듀오와 같이 플레이하는 경우가 많음
  - 바드 코덱스는 본체 버프보다 `Revolution Song` 활용 여부가 중요함

## 한 줄 결론

- 기본 범용 조합: `Mummy + Lich`
- 밀리형 몹 / 고 Magic Resist 몹: `Mummy + Air`
- 테이머 펫이 전선을 이미 잡아주는 상황에서 딜 욕심: `Air + Lich`
- 저중간 난이도 / 저중간 MR / 장기전 딜 욕심: `Vampire + Lich`
- 현재 플레이 기준 Tome 투자 우선순위: `Earth -> Fire -> Air -> Daemon`

## 조합별 추천

### 1. Mummy + Lich

기본 추천 조합이다.

- 언제 쓰나
  - 맵 특성을 아직 잘 모를 때
  - 밀리/캐스터가 섞여 있을 때
  - `Peace` 모드와 `Provo` 모드를 모두 무난하게 굴리고 싶을 때
- 왜 좋은가
  - `Mummy`가 전선 고정과 탱킹을 맡는다
  - `Lich`가 뒤에서 안정적으로 딜을 넣는다
  - `Mummy`의 `Shatter`가 물리 조합일 때 더 빛나긴 하지만, 기본 생존력 자체가 높아서 실전성이 좋다
- 약점
  - `Air`가 들어간 조합보다 고 MR 상대로 킬 속도가 느릴 수 있다
  - `Rag + Lich` 같은 캐스터 특화 조합보다는 캐스터전 대응력이 낮다

### 2. Mummy + Air

밀리형 몹과 고 MR 몹 상대로 가장 강한 축이다.

- 언제 쓰나
  - 상대 몹이 물리 비중이 높을 때
  - 상대 몹의 `Magic Resist`가 높아서 `Vampire + Lich`가 답답할 때
  - `Revolution Song`을 적극 활용하고 싶을 때
- 왜 좋은가
  - `Mummy`는 `Rooted + increased aggro` 기반 탱커라 전선을 잘 잡는다
  - `Shatter`로 `Pierce 25`를 걸면 `Mummy`와 `Air` 둘 다 이득을 본다
  - `Air`는 `Tempest`, `Microburst`, `Whirlwind`로 물리 딜 포텐셜이 높다
- 약점
  - 캐스터맵에서는 `Rag` 계열보다 편하지 않다
  - `Air`는 탱커가 아니라 딜러라, 혼자 맞기 시작하면 생각보다 약하다

### 3. Air + Lich

전선을 다른 누군가가 잡아줄 때 쓰는 딜 지향 조합이다.

- 언제 쓰나
  - 테이머 듀오가 앞라인을 확실히 잡아줄 때
  - 내가 직접 `Mummy`로 전선 안정성을 확보할 필요가 적을 때
  - 고 MR 상대로도 주문딜만으로 싸우기 싫을 때
- 왜 좋은가
  - `Air`가 물리 딜을 담당해서 `Lich`의 주문 저항 상성 문제를 완화한다
  - `Lich`는 `Epic Barrage`로 거리 유지가 편하다
- 약점
  - 네 follower 둘만으로 라인을 잡아야 하는 상황에서는 `Mummy + Lich`보다 불안정하다
  - `Revolution Song`의 provoke anchor로는 `Mummy`보다 덜 안정적이다

### 4. Vampire + Lich

저중간 난이도 파밍이나 장기전 딜 욕심용이다.

- 언제 쓰나
  - 상대 MR이 그렇게 높지 않을 때
  - `Vampire`가 오래 살아서 `Fury`를 잘 쌓을 수 있을 때
  - `Bloodfuel`, `Battlecaster`, `Vengeance`를 살릴 수 있을 때
- 왜 좋은가
  - 장기전 DPS는 높게 뽑을 수 있다
  - `Revolution Song`과 가까운 거리 전투가 잘 맞으면 폭딜 구간이 있다
- 약점
  - `Vampire`는 `Mummy`만큼 탱킹이 안정적이지 않다
  - 둘 다 주문 비중이 커서 고 MR 상대로 약하다
  - 지금 플레이 기준에선 범용 기본 조합으로 보기 어렵다

## Summoner's Tome 투자 방향

## Earth Tome / Ancient Mummy

가장 먼저 투자할 Tome이다.

- 역할
  - 메인 탱커
  - `Provo` second target anchor
  - 물리 조합의 기반
- 우선 업그레이드
  - `Shatter`
  - `Spirit Pact`
  - `Bedrock`
  - `Slam`
  - `Earthpull`
- 해석
  - `Shatter`는 물리딜 조합의 핵심이다
  - `Spirit Pact`는 가장 무난한 전투 성능 상승이다
  - `Bedrock`은 탱커 성격과 잘 맞는다
  - `Slam`, `Earthpull`은 밀리몹 상대로 체감이 좋다
- 네 플레이에서의 위치
  - 가장 중요한 Tome
  - `Mummy + Lich`, `Mummy + Air` 둘 다 이 Tome이 중심이다

## Fire Tome / Lich

두 번째 투자 Tome이다.

- 역할
  - 범용 원거리 딜
  - `Epic Barrage` 기반 후열 딜러
- 우선 업그레이드
  - `Fanning The Flames`
  - `Spirit Pact`
  - `Scorched Earth`
  - `Wildfire`
  - `Glass Cannon`
- 해석
  - `Fanning The Flames`는 `Epic Barrage`를 직접 강화해서 체감이 크다
  - `Scorched Earth`의 `Hex`는 범용성이 좋다
  - `Wildfire`는 멀티타겟 상황에서 효율이 좋다
  - `Glass Cannon`은 딜은 좋지만 어그로 리스크가 있어 후순위다
- 네 플레이에서의 위치
  - 기본 범용 조합의 핵심
  - `Mummy + Lich`를 오래 쓸 생각이면 Earth 다음으로 가장 먼저 올릴 가치가 있다

## Air Tome / Skeletal Fiend

세 번째 투자 Tome다.

- 역할
  - 물리 딜러
  - 고 MR 대응 딜 카드
- 우선 업그레이드
  - `Tempest`
  - `Spirit Pact`
  - `Gale`
  - `Microburst`
  - `Whirlwind`
- 해석
  - `Tempest`가 가장 중요하다
  - `Gale`, `Microburst`, `Whirlwind`는 실제 딜 체감을 만든다
  - `Windshear`, `Cyclone`은 상황형이다
- 네 플레이에서의 위치
  - `Mummy + Air`를 쓸 때 가치가 급상승한다
  - 고 MR 맵을 자주 돌기 시작하면 Fire보다 빨리 올려도 된다

## Daemon Tome / Vampire Thrall

네 플레이 기준으로는 마지막 투자 Tome이다.

- 역할
  - 장기전 주문 딜러
  - 근접 유지형 스펠 딜러
- 우선 업그레이드
  - `Battlecaster`
  - `Bloodfuel`
  - `Vengeance`
  - `Spirit Pact`
  - `Growing Fury`
- 해석
  - 가까이 붙어서 오래 살아 있을수록 강해지는 구조다
  - 그래서 맵 상성이 맞으면 좋지만, 범용성이 높지는 않다
  - `Growing Fury`는 오래 살 때 강하지만, 자주 죽는 환경에서는 우선순위가 떨어진다
- 네 플레이에서의 위치
  - `Vampire + Lich`를 주력으로 굴릴 때만 본격 투자
  - 지금 기준으로는 가장 나중에 투자해도 된다

## 실제 투자 순서 추천

### 기본 운영

- `Earth Tome`
- `Fire Tome`
- `Air Tome`
- `Daemon Tome`

### 고 MR / 물리맵을 자주 도는 경우

- `Earth Tome`
- `Air Tome`
- `Fire Tome`
- `Daemon Tome`

### Vampire를 진짜 주력으로 굴릴 때만

- `Earth Tome`
- `Daemon Tome`
- `Fire Tome`
- `Air Tome`

## 실전 선택 기준

- 맵을 처음 가거나 애매하면 `Mummy + Lich`
- 밀리형 몹이 많거나 마법저항이 높으면 `Mummy + Air`
- 테이머 듀오가 앞라인을 다 잡아주면 `Air + Lich`
- 몹이 잘 안 아프고 저항도 높지 않으며 장기전 딜을 노리면 `Vampire + Lich`

## 현재 스크립트 기준 메모

- 현재 `script/combat/bard-necro.razor`의 `var_provo_follower_kind`는 `vampire / mummy / rag / lich`만 자동 인식한다
- 따라서 `Air`를 `Provo` second target follower로 완전히 자동화하려면 스크립트 수정이 추가로 필요하다
- `Mummy`, `Lich`, `Vampire` 중심 운용은 현재 스크립트와 잘 맞는다
